# Label Empire

Simulation de label musical dans le monde réel (Vite + React + TypeScript).

- `src/engine/` : moteur pur (sans React) — `createGame`, `advanceWeek`, `songQuality`, RNG déterministe.
- `npm test` : tests Vitest du moteur.
- `npm run dev` : interface (à venir, phase 1).
